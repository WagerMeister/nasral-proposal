# Материалы для сборки

`src/` — HTML, стили и данные экранов. `src/history.json` — единый архив мест и ролей; коллекции и памятные события выводятся из него и журнала игр при сборке. `assets/` — изображения. `scripts/` — получение PNG и сборка архива. Итоговые изображения находятся в `../renders/`, описание продукта — в корневых README и ТЗ.

Открыть экраны локально: `src/index.html`.

Из корня репозитория:

```sh
python3 workbench/scripts/build_data.py
uv run --no-project --with playwright python workbench/scripts/render.py
uv run --no-project --with pillow python workbench/scripts/package.py
```

Для рендеринга нужен Chromium Playwright. При отдельной установке его путь можно передать через `NASRAL_CHROMIUM_PATH`. Служебные отчёты и готовый ZIP сохраняются в `verification/` и `dist/`; в Git они не входят. В презентационный ZIP попадают только README, ТЗ и 15 изображений экранов с двумя обзорными листами. Перечень состояний задаёт `scripts/presentation.py`; рендеринг и упаковка используют один список. Проверки включают полноту коллекций всех участников, условия регалий, переходы к результатам, фильтры событий и невыбранные варианты аукциона. Дополнительно проверяются единый состав из девяти человек, полнота страниц списков, сводка фильтрованных аукционов, прямые ссылки сравнения, порядок последних игр и возврат с сохранением контекста. Положительные пути клипа/VOD/таймкода проверяются на данных только в памяти браузера; в публичных примерах вымышленных записей нет.
