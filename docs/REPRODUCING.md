# Повторное получение рендеров

Эта инструкция относится только к визуальной сборке предложения. Она не описывает архитектуру будущего сайта NASRAL.

## Без установки

Откройте `index.html` для галереи или `src/index.html` для локального просмотра. Все ресурсы лежат рядом; внешние шрифты, CDN-скрипты и API для просмотра не требуются. Внешняя ссылка голосования открывается только по явному действию пользователя.

Основные переходы, сортировки, фильтры и локальный черновик работают. Отправки голосов, платежей, обновления настоящего турнира и прикреплённых VOD нет. Состояние 12 в галерее открывается как **явно заданный пример заполненного состава**; обычное открытие проверки выбора не должно автоматически выбирать людей за пользователя.

## Сборка изображений

Нужны Python, `uv` и Chromium для Playwright. Рендеры получены из HTML/SVG напрямую при viewport 1920×1080 и device scale factor 1, без увеличения маленького исходного PNG.

```sh
python3 scripts/build_data.py
uv run --no-project --with playwright playwright install chromium
uv run --no-project --with playwright python scripts/render.py
uv run --no-project --with pillow python scripts/package.py
```

Если Chromium уже установлен отдельно, можно указать путь через `NASRAL_CHROMIUM_PATH`. Скрипт также обнаруживает существующий кэш Chromium Playwright на macOS. Полные результаты работы браузера записываются в `verification/browser.json`, а не смешиваются с текстом предложения.

`scripts/render.py` проверяет 12 состояний, доступность картинок, компоновку и основные взаимодействия. `scripts/package.py` создаёт обзорные листы, галерею, проверяет сценарные агрегаты и локальные ссылки, записывает контрольные суммы и собирает ZIP в `dist/`.

HTML-предпросмотр рассчитан на десктоп. Доступность полноценного продукта, мобильные интерфейсы и интеграции являются требованиями ТЗ, а не свойствами, доказанными этим скриптом.
